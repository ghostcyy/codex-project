ACTION PLAN

2026年机构牌照申请建议路径

Phase 1: 摸底

法域选择与架构

评估业务主要覆盖区。推荐以新加坡或香港作为离岸金融创新中心，同时在卢森堡/爱尔兰获取 MiCA 欧洲通行证。

Phase 2: 资本

资本金注入

按当地监管要求冻结法定货币作为实缴资本，通常要求自有资金至少占预期发行规模的 2%-5%。

Phase 3: 审计

IT与风控审计

聘请外部四大进行 AML 流程、冷热钱包私钥管理机制、智能合约逻辑的全方面模拟压力测试。

Phase 4: 发行

沙盒毕业与铸造

获得正式信托或支付机构牌照，在受限白名单网络内进行首次铸币，并逐步开放 API 接口给零售渠道。
